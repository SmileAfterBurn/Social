# Посібник з функцій захисту дітей та доступності

## 🛡️ Захист дітей

### Огляд
Модуль "Захист дітей" надає швидкий доступ до критично важливих ресурсів для захисту дітей в Україні.

### Як користуватися

#### 1. Відкрити модуль захисту дітей
- Натисніть кнопку **"Захист дітей"** (з іконкою щита) у верхньому меню
- Кнопка має яскравий рожево-червоний градієнт для видимості

#### 2. Екстрена допомога
Модуль показує екстрені контакти в червоному блоці попередження:
- **102** — Поліція (негайна допомога)
- **116 111** — Національна дитяча гаряча лінія (цілодобово)

#### 3. Національні гарячі лінії
Доступні 4 спеціалізовані служби:

**116 111** — Національна гаряча лінія з протидії торгівлі людьми
- Цілодобово, безкоштовно, конфіденційно
- Для дітей у складних життєвих обставинах

**0 800 501 720** — Уповноважений Президента з прав дитини
- Консультації з питань захисту прав дітей
- Допомога в кризових ситуаціях

**0 800 500 335** — Ла Страда-Україна
- Протидія торгівлі людьми
- Допомога жертвам експлуатації
- Юридичні та психологічні консультації

**102** — Ювенальна поліція
- Протидія домашньому насильству
- Захист дітей від насильства та експлуатації

#### 4. Центри захисту дітей
6 центрів у великих містах:
- Київ — Національна соціальна сервісна служба
- Львів — Служба у справах дітей
- Одеса — Центр соціальних служб для дітей та молоді
- Дніпро — Центр соціальних служб для дітей та сімей
- Харків — Кризовий центр для дітей (цілодобово)
- Запоріжжя — Центр підтримки сімей та дітей

Кожен центр показує:
- Адресу та контактні дані
- Години роботи
- Перелік послуг
- Екстрений контакт (якщо є)

#### 5. Фільтрація за категорією
- Під пошуковою панеллю знайдіть фільтри категорій
- Натисніть **"Захист дітей"** для показу тільки релевантних організацій
- Натисніть повторно або "Скинути фільтр" для скасування

## ♿ Доступність

### Огляд
Функції доступності роблять додаток зручним для людей з особливими потребами.

### Як користуватися

#### 1. Відкрити панель доступності
- Натисніть кнопку з іконкою **ока (👁️)** у верхньому меню
- Відкриється панель налаштувань доступності

#### 2. Налаштування розміру тексту
Виберіть один з трьох розмірів:
- **Звичайний** — стандартний розмір тексту
- **Великий** — збільшений текст для кращої читабельності
- **Дуже великий** — максимальний розмір для користувачів з вадами зору

Налаштування зберігається автоматично і застосовується при наступних відвідуваннях.

#### 3. Висока контрастність
- Увімкніть режим високої контрастності для покращення читабельності
- Підвищує контраст і насиченість кольорів
- Корисно при яскравому освітленні або для людей з вадами зору
- Налаштування зберігається автоматично

#### 4. Клавіатурна навігація
Усі елементи доступні через клавіатуру:
- **Tab** — перехід між елементами
- **Enter/Space** — активація кнопок
- **Escape** — закриття модальних вікон
- **Стрілки** — навігація в списках

#### 5. Підтримка програм екранного читання
- Усі кнопки мають ARIA-мітки
- Модальні вікна мають правильні ARIA-атрибути
- Інтерактивні елементи анонсуються коректно

## 🎯 Швидкі дії

### Екстрена ситуація з дитиною?
1. Натисніть **"Захист дітей"** у верхньому меню
2. У червоному блоці натисніть **102** або **116 111**
3. Телефонуйте негайно

### Потрібна консультація?
1. Відкрийте **"Захист дітей"**
2. Виберіть відповідну гарячу лінію
3. Зателефонуйте або відвідайте веб-сайт

### Покращити читабельність?
1. Натисніть іконку **ока (👁️)**
2. Виберіть більший розмір тексту
3. Увімкніть високу контрастність
