## 📋 ПОКРОКОВА ІНСТРУКЦІЯ

### Крок 1: Підготовка API ключів

Перед розгортанням підготуйте наступні API ключі:

#### Обов'язкові:
- **Google Maps API Key** - для роботи карти
  - Отримати: https://console.cloud.google.com/google/maps-apis
  - Увімкніть APIs: Maps JavaScript API, Places API, Geocoding API

- **Google Gemini API Key** - для AI асистентки (пані Думки)
  - Отримати: https://aistudio.google.com/app/apikey

#### Опціонально (якщо використовуєте Firebase):
- Firebase Configuration Keys
  - Отримати з Firebase Console: https://console.firebase.google.com

---

### Крок 2: Розгортання на Vercel

#### 🌟 ВАРІАНТ 1: Швидке розгортання (рекомендовано)

1. **Відкрийте посилання:**
   ```
   https://vercel.com/new/clone?repository-url=https://github.com/SmileAfterBurn/Social
   ```

2. **Авторизуйтесь** через GitHub

3. **Додайте змінні середовища:**
   - Натисніть "Environment Variables"
   - Додайте (мінімум):
     ```
     VITE_GOOGLE_MAPS_API_KEY = ваш_ключ_google_maps
     VITE_GEMINI_API_KEY = ваш_ключ_gemini
     ```

4. **Натисніть "Deploy"**

5. **Чекайте 2-3 хвилини** - Vercel автоматично:
   - Завантажить код
   - Встановить залежності
   - Зібере проект
   - Опублікує його

---

#### 🎯 ВАРІАНТ 2: Через Dashboard Vercel

1. **Перейдіть на:** https://vercel.com/new

2. **Імпортуйте проект:**
   - Натисніть "Import Git Repository"
   - Оберіть `SmileAfterBurn/Social`
   - Натисніть "Import"

3. **Vercel автоматично визначить:**
   - Framework: Vite ✅
   - Build Command: `npm run build` ✅
   - Output Directory: `dist` ✅

4. **Додайте Environment Variables:**
   
   Мінімальні (обов'язкові):
   ```
   Name: VITE_GOOGLE_MAPS_API_KEY
   Value: AIzaSy... (ваш ключ)
   
   Name: VITE_GEMINI_API_KEY
   Value: AIzaSy... (ваш ключ)
   ```
   
   Опціонально (Firebase):
   ```
   VITE_FIREBASE_API_KEY
   VITE_FIREBASE_AUTH_DOMAIN
   VITE_FIREBASE_PROJECT_ID
   VITE_FIREBASE_STORAGE_BUCKET
   VITE_FIREBASE_MESSAGING_SENDER_ID
   VITE_FIREBASE_APP_ID
   ```

5. **Натисніть "Deploy"**

---

#### 💻 ВАРІАНТ 3: Через Vercel CLI

## ⚙️ Налаштування Custom Domain (Опціонально)

1. Відкрийте проект в Vercel Dashboard
2. Перейдіть в **Settings → Domains**
3. Додайте ваш домен (наприклад: `social.smileafterburn.org`)
4. Налаштуйте DNS записи як вказано Vercel
5. Чекайте підтвердження (зазвичай 5-60 хвилин)

## 🆘 Troubleshooting

### Проблема: Build fails
**Рішення:**
- Перевірте логи в Vercel Dashboard
- Переконайтесь що всі залежності в `package.json`
- Перевірте версію Node.js (рекомендовано: 18.x+)

### Проблема: Карта не завантажується
**Рішення:**
- Перевірте що `VITE_GOOGLE_MAPS_API_KEY` встановлений
- Перевірте що API key має дозволи:
  - Maps JavaScript API
  - Places API
  - Geocoding API
- Увімкніть біллінг в Google Cloud Console

### Проблема: AI асистентка не працює
**Рішення:**
- Перевірте що `VITE_GEMINI_API_KEY` встановлений
- Перевірте ліміти на https://aistudio.google.com

### Проблема: 404 на внутрішніх роутах
**Рішення:**
- Це вже налаштовано в `vercel.json`
- Якщо проблема залишається, перевірте конфігурацію
