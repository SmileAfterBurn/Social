# Підключення домену — Соціальна мапа турботи

Коротко: сайт доступний за доменом **https://соціальна-мапа-турботи.in.ua**. Нижче — покрокова інструкція підключення домену до Firebase Hosting (або GCS), включаючи DNS-записи і підказки.

---

## 1) Підготовка
- Підготуйте доступ до панелі реєстратора домену (де ви купували/реєстрували домен).
- Якщо реєстратор не підтримує введення IDN у Unicode, використовуйте punycode: `xn-----6kcabai0duamijkkre2adp2c4htj.in.ua`.
  - Приклад перетворення в Linux/Mac: `python3 -c "print('соціальна-мапа-турботи.in.ua'.encode('idna').decode())"`

## 2) Добавлення домену у Firebase Hosting
1. Відкрийте Firebase Console → Hosting → виберіть проект, у якого є сайт **social-map-of-care**.
2. Натисніть **Add custom domain**.
3. Введіть домен: `соціальна-мапа-турботи.in.ua` (або його punycode, якщо необхідно).
4. Firebase покаже набір DNS-записів для верифікації (зазвичай TXT record). Скопіюйте наведені значення.
5. У панелі реєстратора додайте наведений TXT-запис (ім’я/host, значення). Це підтверджує володіння доменом.
6. Після додавання TXT, у Firebase натисніть **Verify** та дочекайтесь статусу верифікації (може зайняти до 24 годин через DNS propagation).

## 3) Налаштування DNS для хостингу
- Firebase може попросити додати A-записи або CNAME records (в залежності від конфігурації). Додайте ті записи, які вкаже Firebase.
- Після успішної верифікації Firebase автоматично налаштує SSL (Let's Encrypt) — SSL сертифікат випускається автоматично, може зайняти деякий час.

## 4) CI/CD та автоматичний деплой
- У репозиторії додано `cloudbuild.yaml` (для GCS) та приклад GitHub Actions workflow для деплою на Firebase (див. `.github/workflows/deploy.yml` — якщо ви увімкнете його, потрібно задати секрет `FIREBASE_TOKEN` в GitHub Secrets).
- Для генерації `FIREBASE_TOKEN` локально використайте: `firebase login:ci` (після встановлення Firebase CLI) і додайте отриманий токен у Secrets.

## 5) Перевірте PWA / SEO
- У репозиторії вже оновлено `vite.config.ts` (manifest) та `index.html` (canonical/OG meta). Після деплою перевірте:
  - `https://соціальна-мапа-турботи.in.ua/` відкриває сайт
  - У браузері у вкладці Application → Manifest бачите `lang: "uk"` і правильні назви
  - Open Graph мета-теги для соціальних мереж

## 6) Додаткові поради
- Якщо віддача файлів здійснюється через GCS/Load Balancer — перевірте, який бекенд служить файли і додайте домен у відповідне місце (GCP LB/docs).
- Пропишіть у реєстраторі TTL не дуже мале значення (наприклад, 3600), щоб уникнути зайвих запитів під час налаштувань.

---

Якщо хочете, можу автоматично надіслати Firebase TXT-запис та перевірити статус верифікації, якщо дасте доступ або вставите значення, які Firebase показує під час додавання домену.
